# Optional image contributions

v0.1.0 publishes URL metadata only. To add an image file, submit its original
source, issuer reference, check date, SHA256, dimensions, format and the applicable
asset-use/redistribution terms in a PR. Use a stable company-id directory and keep
individual notices with the asset. The validator currently accepts URL records
only; asset delivery needs a schema update before files become consumable entries.

Do not import NVSTly's noncommercial image pack under this repository's MIT license
or assume that an unlicensed GitHub collection grants redistribution rights.
Prefer issuer-provided brand assets with documented terms. Keep original artwork
and separate theme variants; do not invent a corporate logo to fill a gap.
